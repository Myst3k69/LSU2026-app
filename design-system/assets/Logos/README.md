# Logos

Logotype « BuildOS » et monogramme « B. », vectorisés depuis Schibsted Grotesk ExtraBold. Couleurs figées dans les fichiers (une image SVG n'hérite pas de `currentColor`) ; en code, préférer le composant `Logo`.

- `buildos-logo.svg` — Logotype principal : « Build » en `ink` (#0c0c0d), « OS » en `bleu` (#0a3bf0). Sur `paper` ou `surface`.
- `buildos-logo-ink.svg` — Logotype monochrome, encre unique `ink` (#0c0c0d). Impression une couleur, tampons.
- `buildos-logo-reverse.svg` — Logotype inversé, encre unique `surface` (#fbfaf6). Sur `ink` ou sur `bleu`.
- `buildos-icon.svg` — Icône d'application : carré `bleu`, « B. » en `on-bleu`. Favicon, application mobile, avatar.
- `buildos-icon-ink.svg` — Icône sur carré `ink`, « B » en `surface`, point en `bleu`.
