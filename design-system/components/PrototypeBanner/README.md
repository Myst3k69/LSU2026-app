# PrototypeBanner

Le bandeau fixe « Prototype de vision – données fictives », en haut de chaque écran de vision.

- Aplat `ink`, texte `surface` en `label` capitales ; `position: sticky` en haut de page.
- Obligatoire sur tout écran montré hors de l'équipe tant que les données sont fictives.
- Sur mobile, réduire l'interlettrage (0.1em, 10px) pour tenir sur une ligne.
