# TaskStatus

Le statut d'une tâche : À faire, Faite ou Reportée — toujours un mot et une icône, jamais la couleur seule.

- À faire : contour `line-control`, texte `ink-2`, cercle vide.
- Faite : fond `vert-soft`, texte `vert`, coche.
- Reportée : fond `paper-deep`, texte `ink-3`, flèche de report.
- Le consommateur fournit `status` ; les libellés sont fixes.
