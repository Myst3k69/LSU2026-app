# DomainHeader

L'en-tête d'un domaine du plan : grand numéro serif, nom, compte des tâches faites, oubliées ouvertes et progression.

- Le consommateur fournit `index` ("01" à "08"), `name`, `icon`, `done`, `total` et `forgotten` (oubliées encore ouvertes).
- Un filet `ink` de 1,5px ferme l'en-tête : c'est la structure éditoriale du système, comme les sections numérotées de la maquette.
- `compact` pour le mobile : numéro `numeral-s`, progression sous le titre.
- Les huit domaines, dans l'ordre : Produit, Marché & clients, Juridique & admin, Finance, Marketing & acquisition, Tech, Opérations, Veille.
