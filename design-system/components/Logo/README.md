# Logo

Le logotype BuildOS et son monogramme « B. », dessinés en Schibsted Grotesk ExtraBold vectorisée.

- `full` + `color` : « Build » en `ink`, « OS » en `bleu`, sur `paper` ou `surface`. C'est la version par défaut.
- `reverse` : tout en `surface`, sur `ink` ou sur `bleu`.
- `ink` : monochrome pour les impressions une couleur.
- `icon` : carré `bleu` à radius proportionnel, « B. » en `on-bleu` — favicon, application mobile, avatar de projet. Version `ink` : carré noir, point bleu.
- Hauteur minimale : 20px pour le logotype, 24px pour l'icône. Zone de protection : la hauteur du « B » tout autour.
