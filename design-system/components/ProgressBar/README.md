# ProgressBar

Barre d'avancement : piste `paper-deep`, remplissage `bleu` (ou `ink`).

- `value` / `max` en nombre de tâches, jamais en pourcentage inventé.
- `sm` (4px) dans les en-têtes de domaine et listes, `md` (6px) pour l'avancement global.
- Toujours accompagnée d'un texte ("2/4 faites", "37 %") ; `label` fournit le nom accessible.
