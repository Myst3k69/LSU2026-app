# Icon

Le jeu d'icônes linéaires du système : grille 24px, trait 1,75 arrondi, couleur `currentColor`.

- Huit icônes de domaine : cube (Produit), users (Marché & clients), scale (Juridique & admin), euro (Finance), megaphone (Marketing & acquisition), code (Tech), sliders (Opérations), eye (Veille).
- `sparkle` (pleine) est réservée au copilote IA ; `alert` au signal « Souvent oubliée ».
- Décoratives par défaut (aria-hidden) ; passer `label` quand l'icône est seule porteuse de sens.
- Le consommateur fournit `name` et `size` (14, 16, 18, 20 ou 24).
