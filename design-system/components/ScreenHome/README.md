# ScreenHome

Écran Accueil (desktop, 1440px) : le fondateur décrit son projet et lance « Générer mon plan ».

- Titre manifeste `display-xl`, dernier mot en `bleu` avec son point ; zone `Input` `lg` dans un panneau `shadow-frame`.
- Puces de complétude dans le pied du champ (Ville, Cible, Modèle de revenus cochés ; Budget, Équipe à ajouter).
- Bandeau bas : les huit domaines numérotés, les étapes souvent oubliées en `orange-ink`.
- Données fictives : projet Créno Vélo (réservation de réparateurs vélo à domicile, Lyon).
