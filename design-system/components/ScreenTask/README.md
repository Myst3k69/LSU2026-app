# ScreenTask

Écran Détail d'une tâche (desktop) : « Rédiger les CGU de la plateforme et le modèle de CGV ».

- Pourquoi c'est indispensable : phrase `lead-serif`, trois raisons avec leur référence, encadré « Pourquoi elle est souvent oubliée ».
- Ressources : documents générables (un déjà généré) et organismes officiels (service-public, DGCCRF, médiation de la consommation, CNIL).
- Colonne droite : conversation avec le copilote IA rattachée à la tâche, champ de message en pied.
- Rappel : les trames générées se font relire par un professionnel du droit.
