# ScreenPlan

Écran Plan (desktop) : les 27 tâches du projet regroupées par domaine, avec statuts et badges « Souvent oubliée ».

- En-tête : titre, résumé du projet, compteurs (tâches, faites, reportées, oubliées ouvertes) et progression globale.
- Filtres par statut, encadré `orange-soft` qui pousse à traiter d'abord les étapes souvent oubliées.
- Grille de huit sections `DomainHeader` + `TaskCard` compactes ; les tâches faites sont repliées, sauf dans Juridique & admin.
- Pleine hauteur de page (défilement inclus).
