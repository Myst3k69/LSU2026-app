# ForgottenBadge

Le badge « Souvent oubliée » : signale une étape que les fondateurs négligent fréquemment.

- Fond `orange-soft`, texte et icône `orange-ink` (5.3:1). L'orange vif `orange` est réservé aux points et pastilles.
- Toujours avec l'icône d'alerte ; la version `compact` (icône seule) porte un libellé accessible et un title.
- Le badge reste affiché quand la tâche est faite : il décrit la nature de la tâche, pas son état.
- `children` remplace le libellé pour un compteur (« 6 souvent oubliées »).
