# ScreenPlanMobile

Écran Plan en mobile (390px) : progression, filtres défilants, sections de domaine compactes et barre d'onglets.

- `DomainHeader` `compact` ; Produit (faites repliées) et Juridique & admin (tout déplié) ouverts, les six autres domaines repliés en lignes.
- Barre d'onglets fixe : Accueil, Plan, Tableau, Copilote.
